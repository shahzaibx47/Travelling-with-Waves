# Travelling with Waves

A responsive travel and beach destination website rebuilt from the supplied project assets.

## Run the website

### Option 1 — VS Code / Live Server
Open this folder in VS Code and use **Live Server** on `index.html`.

### Option 2 — Python local server
From this folder run:

```bash
python -m http.server 5500
```

Then open `http://127.0.0.1:5500/` in a browser.

## Main files

- `index.html` — page structure and content
- `style.css` — responsive design and styling
- `script.js` — navigation, dark mode, carousel, video, modal and newsletter interactions
- `images/` — supplied project images, logos and video
- `Travelling_with_Waves_Project_Proposal.docx` — project proposal

## Important

All supplied media is referenced with relative paths such as `images/home1.jpg`. No `C:\Users\...` paths are required, so the project can be moved to another computer without breaking the images.
